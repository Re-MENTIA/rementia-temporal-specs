# Rementia Temporal Specs

## Conversational Agents Accessibility Design Guidelines for People Living With Dementia

This repository provides verification proposition sets and modules for developing accessible conversational agents (CAs) for people living with dementia (PLwD). Based on evidence-based speech accommodation patterns used by healthcare professionals, this project offers practical guidelines and testing tools for creating more effective and compassionate AI communication systems.

## 🎯 Purpose

Healthcare professionals naturally adapt their communication when interacting with PLwD, employing specific speech accommodation strategies that enhance understanding and maintain dignity. This repository translates these proven communication patterns into:

- **Design Guidelines**: Evidence-based principles for CA development
- **Verification Propositions**: Testable hypotheses based on clinical communication research
- **Verification Modules**: Automated tools to assess CA compliance with accessibility standards
